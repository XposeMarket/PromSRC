## Functional and safety PASS

Zero console errors; clear goal within 10 seconds; playable first minute and complete round on mobile emulator; solo and two-player social/invite checks; real data save/leave/rejoin; server-authoritative state and validated remotes; scanned assets; original IP. Missing required runtime capability is NOT TESTED, never PASS, unless an explicit owner-approved scope exception exists.

Local pre-staging safety/runtime tests occur before restricted staging. Staging requires verified ownership/visibility, isolated test data and actual tool approval, NOT final QA PASS. Probe then performs persistence/multiplayer checks and combines same-version local plus staging evidence into final PASS. Manager may only publish publicly after that final PASS under standing authorization; Probe then smoke-tests the public version. A newer build invalidates prior PASS until retested.

Edit-mode screenshots can support layout review but cannot satisfy runtime/play evidence. Save playable footage/screenshots with build version, time, author, executed/not-tested checks and reference pairing. A written score without the required evidence is not acceptance.
