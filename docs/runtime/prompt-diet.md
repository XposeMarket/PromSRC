# Prompt overhead boundaries

The base TOOLS menu is generated from the actual core builder and canonical category manifest, not an independently maintained tool list. Activated-category policy remains in the prompt. Unattended actor surfaces omit question-card/login-wait schemas, while direct chats retain them. Final-action approval and delivery schemas deliberately remain: scheduled approvals fail fast through the scheduler's authority boundary, and output delivery is legitimate unattended work.

TODAY_NOTES defaults to a 2,000-character total budget including headers. Newest open IDs are reserved first, then short open summaries and at most three recent nonopen notes. If IDs alone exceed the cap, retain newest whole IDs and explicitly advertise overflow with a memory-search pointer. The note store is never truncated. USER/SOUL content is not shortened: context panel estimates count the same full memory-profile loader and label over-6,000-character persona sections with a size warning.

The synthetic offline harness calls real builders with a 24k-character USER fixture and 12 open notes. Token estimates use chars/4; calibrated estimates multiply by the audit's 1.64 observed factor. Neither measure is provider-tokenizer usage. Provider adapters and actual cache breakpoints are outside this change. Live model/device evidence remains required before claiming deployment.
