# Luna Benchmark Studio landing page

## Files created

- `index.html` — semantic, self-contained landing page markup.
- `styles.css` — local visual system, component styling, and responsive layout rules.

## Page structure

- A semantic `header` with the Luna Benchmark Studio brand and primary navigation.
- A hero section with the headline “Make every signal count,” supporting copy, two navigation actions, and a decorative moon-and-signal illustration built entirely with CSS.
- A principles strip introducing clarity, rigor, and momentum.
- An approach section containing three feature cards: Frame, Measure, and Move.
- A dark call-to-action panel with a mailto link for starting a conversation.
- A semantic footer with copyright, positioning statement, and back-to-top link.

## Responsive verification

Responsive behavior was verified by inspecting the final stylesheet for the required media-query rules and checking that the layout changes from a two-column hero and feature grid to stacked content at viewport widths of 820px and below. A second breakpoint at 430px adjusts the moon illustration and compact mobile controls. Browser verification was not performed.
