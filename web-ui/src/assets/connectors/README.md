# Connector brand marks

These SVGs are the actual brand marks from Simple Icons v16.28.0, pinned at
the source URL used when this bundle was created:

`https://cdn.jsdelivr.net/npm/simple-icons@16.28.0/icons/<slug>.svg`

They are bundled so the desktop Electron/web UI does not depend on a runtime
CDN request. Brand names and marks remain the property of their respective
owners; retain the upstream Simple Icons license and trademark guidance when
redistributing the application.
