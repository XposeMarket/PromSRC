# Connector brand marks

These SVGs are the actual brand marks from Simple Icons v16.28.0, pinned at
the source URL used when this bundle was created:

`https://cdn.jsdelivr.net/npm/simple-icons@16.28.0/icons/<slug>.svg`

They are bundled so the desktop Electron/web UI does not depend on a runtime
CDN request. Brand names and marks remain the property of their respective
owners; retain the upstream Simple Icons license and trademark guidance when
redistributing the application.

Catalog additions use the same pinned Simple Icons distribution. Windows uses [windows11.svg from v11.15.0](https://cdn.jsdelivr.net/npm/simple-icons@11.15.0/icons/windows11.svg). The MCP protocol mark identifies unbranded MCP servers, not a vendor endorsement.

Color images are publisher artwork, bundled locally as PNG without changing proportions. Sources: [Canva app icon](https://static.canva.com/domain-assets/canva/static/images/android-192x192-2.png), [Higgsfield app icon](https://higgsfield.ai/icon.png), [Shopmonkey site icon](https://www.datocms-assets.com/38431/1671769668-shopmonkey-logo.svg?w=128&h=128&fm=png), [Websembli publisher wordmark](https://websembli.com/wp-content/uploads/2023/04/websembliblacklogopx-1.jpg). These remain publisher trademarks; provenance does not grant a trademark license.
