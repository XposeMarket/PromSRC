# Grounded Claim Review

Use this supplement when a research answer contains several factual claims or a consequential recommendation.

## Claim map

Break the answer into claims. For each claim, record the source URL, source date, event date if different, exact supporting passage or data, source quality, and confidence. Label each statement as verified fact, attributed claim, inference, estimate, or unknown.

## Source discipline

Prefer primary and authoritative sources, then triangulate material or disputed claims with an independent source. Fetch the underlying page before relying on a search snippet. Treat a domain-restricted search result as discovery, not proof. Preserve URLs and retrieval dates.

## Completeness check

Before finalizing, ask whether every changing or decision-relevant claim has nearby support, whether counterevidence is represented, whether sources are stale or syndicated, and whether the conclusion goes beyond the evidence. State what could not be verified.

## Output

Return a concise evidence table or inline citations, a separation of facts from inference, confidence and uncertainty, and the next validation step when evidence is incomplete. Never manufacture precision or cite a source that was not actually read.
